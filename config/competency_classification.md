# Classification Rules:
# 1. Common competencies are those that:
#    - Apply across multiple industries
#    - Have established training markets
#    - Are foundational or widely adopted
#    - Have standard certifications available
#
# 2. Niche competencies are those that:
#    - Require specialized expertise
#    - Are emerging or cutting-edge technologies
#    - Apply to specific industries only
#    - Have limited training providers
#    - Require custom development programs
