# Examples

This directory contains example scripts demonstrating how to use the LNA Bot.

## Available Examples

### `simple_demo.py`
Basic demonstration of LNA Bot functionality including:
- Loading configuration
- Analyzing CSV files
- Getting training recommendations
- Exporting results

## Usage

Run the examples from the project root:

```bash
# Simple demonstration
python examples/simple_demo.py

# Interactive terminal interface
python main.py
```

## Creating Your Own Examples

When creating new examples:
1. Import LNABot from the src directory
2. Use relative paths for data files
3. Handle exceptions appropriately
4. Include clear documentation
